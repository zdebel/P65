# P65 firmware

Firmware for the Raspberry Pi Pico (RP2040) that is the heart of the P65: it runs a real
W65C02S, serves its memory and I/O, emulates a TMS9918 on an ILI9341 LCD, scans the keyboard and
keeps a small flash file system. Two cores:

| core | job | files |
|---|---|---|
| 1 | the 65C02 bus: answers every read / write within ~125 ns (PIO clock + hand-written loop in RAM) | `65c02.c`, `65c02_clk.pio` |
| 0 | renders the picture line by line (DMA to the LCD), keyboard matrix, 60 Hz VSYNC and the CPU /IRQ line, flash storage, USB serial protocol | `video.c`, `tms9918.c`, `ili9341.c`, `keyboard.c`, `storage_fw.c` |

## Build

Everything needed except the compiler is in this directory (`sdk/` is an extract of the Pico SDK 1.5.1,
see [sdk/README.md](sdk/README.md)). Needs the Arm GNU toolchain (`arm-none-eabi-gcc`), GNU make and Python 3.

```
make                    # -> out/p65.uf2  (Windows: mingw32-make from MSYS2, or make from scoop)
make IRQ_DEBUG=1        # + VSYNC / IRQ / LCD counters once a second on the USB serial
make SHOW_FPS=1         # + FPS badge on the LCD
make clean
make flash              # copies out/p65.uf2 to a Pico in BOOTSEL mode (Windows only for now)
```

The build is bit-identical to the one made with the SDK's own CMake. To move to a newer SDK see
[sdk/README.md](sdk/README.md).

## Layout

```
src/, include/   firmware sources (include/rom.h is the generated ROM image, src/65c02_clk.pio.h is generated by pioasm)
sdk/             the needed part of the Pico SDK 1.5.1 + TinyUSB 0.15.0, and sdk.mk (file list for the Makefile)
Makefile         the build
rom/             the BASIC / monitor ROM in 65C02 assembly (ca65): p65_basic.a65 + fpp65.a65 + storage.a65
examples/        RAM and ROM-image demos (vsync.a65, vdpdemo.a65)
tools/           make_rom.py (ROM -> include/rom.h), asm.py (assemble any .a65), bin2uf2.py, p65store.c + build_storelib.py (test reference)
tests/           host tests: flash file system with power-cut injection, C code vs. the emulator's Python port, ROMCTL
docs/            MEMORY_MAP.md, STORAGE.md, VSYNC.md
```

## ROM

`include/rom.h` is generated; after changing anything in `rom/`:

```
python tools/make_rom.py              # needs ca65 / ld65 (cc65)
python tools/make_rom.py --check      # is include/rom.h up to date?
python tools/make_rom.py --bin ../emulator/rom/p65_basic.bin    # same image for the emulator
```

## Tests

```
python -m unittest discover -s tests
```

They need a C compiler (`cc` / `gcc` / `clang`) and the emulator directory next to this one.
